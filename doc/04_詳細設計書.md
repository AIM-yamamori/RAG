## 3. チャンク分割処理(`ingest/chunker.py`) ※変更なし

### 3.1 処理概要

就業規則のMarkdownファイルを読み込み、「条」単位(`## 第n条(タイトル)`)を1チャンクとして分割する。

### 3.2 関数仕様

#### `parse_markdown_content(filename: str, text: str) -> list[dict]`

| 項目 | 内容 |
|---|---|
| 引数 | `filename`: ファイル名、`text`: Markdownテキスト |
| 戻り値 | チャンク情報の辞書のリスト |
| 処理概要 | 正規表現 `^##\s+(第\d+条)(.*)$` で条文見出しを検出し、条ごとに分割する |

**戻り値の構造例**

```python
[
    {
        "source_file": "04_休暇制度.md",
        "chapter_title": "第4章 休暇制度",
        "article_no": "第28条",
        "article_title": "年次有給休暇",
        "content": "## 第28条(年次有給休暇)\n\n1. 会社は..."
    },
    ...
]
```

## 4. ベクトル化処理(`ingest/embedder.py`) ★全面変更

### 4.1 変更概要

Vertex AI SDK(`vertexai.language_models.TextEmbeddingModel`)から、Gemini API(`google.generativeai.embed_content`)に変更した。変更理由はVertex AI SDKがPython 3.12環境で同一ベクトルを返す不具合が発生したためである。

### 4.2 実装コード

```python
import os
import google.generativeai as genai
from dotenv import load_dotenv

load_dotenv()
genai.configure(api_key=os.getenv("GEMINI_API_KEY"))

def get_embedding(text: str) -> list[float]:
    """
    Gemini API(gemini-embedding-001)を用いて768次元のベクトルを取得する
    output_dimensionality=768 を明示指定することで768次元に固定する
    (指定なしの場合はデフォルト3072次元が返るため必須)
    """
    result = genai.embed_content(
        model="models/gemini-embedding-001",
        content=text,
        task_type="retrieval_document",
        output_dimensionality=768
    )
    return result["embedding"]
```

### 4.3 重要な設計上の注意点

| 項目 | 内容 |
|---|---|
| モデル名 | `models/gemini-embedding-001`(models/プレフィックス必須) |
| 次元数 | `output_dimensionality=768` を**必ず指定**する。未指定時は3072次元が返りDBとミスマッチになる |
| task_type | 取り込み・検索ともに `retrieval_document` を使用 |
| Vertex AI | 使用しない(SDK不具合のため) |

### 4.4 モデル選定の経緯

| 試したモデル | 結果 |
|---|---|
| Vertex AI / text-embedding-004 | NG: Python 3.12環境で全質問に同一ベクトルを返す不具合 |
| models/text-embedding-004 (Gemini API) | NG: 404エラー(v1beta未対応) |
| models/embedding-001 (Gemini API) | NG: 404エラー(v1beta未対応) |
| **models/gemini-embedding-001 (Gemini API)** | **OK: 正常動作確認済み** |

利用可能なモデルは `genai.list_models()` で確認できる。

## 6. DB接続処理(`app/db.py`) ※変更なし

### 6.1 接続方式

Cloud SQL Python Connector(pg8000ドライバ)を使用。psycopg2-binaryはPython 3.12でビルドエラーが発生するため使用しない。

### 6.2 関数仕様

#### `search_similar_chunks(query_embedding: list[float], top_k: int = 3) -> list[dict]`

| 項目 | 内容 |
|---|---|
| 引数 | `query_embedding`: 768次元のベクトル、`top_k`: 取得件数 |
| 戻り値 | 類似度上位のチャンク情報リスト |
| SQLの演算子 | `<=>` (pgvectorのコサイン距離演算子) |

**実行SQL**

```sql
SELECT source_file, chapter_title, article_no, article_title, content,
       1 - (embedding <=> CAST(:vec AS vector)) AS similarity
FROM rule_chunks
ORDER BY embedding <=> CAST(:vec AS vector)
LIMIT :top_k;
```

**注意:** カラム値へのアクセスはpg8000の制約により属性アクセス(`r.source_file`)ではなくインデックスアクセス(`r[0]`)を使用する。

```python
results.append({
    "source_file": r[0],
    "chapter_title": r[1],
    "article_no": r[2],
    "article_title": r[3],
    "content": r[4],
    "similarity": float(r[5]),
})
```

## 7. LLM呼び出し処理(`app/llm_client.py`) ※モデル名変更

### 7.1 変更点

`gemini-1.5-flash` → `gemini-2.5-flash-lite` に変更。`gemini-2.0-flash`は無料枠クォータ超過が発生したため使用しない。

### 7.2 実装コード

```python
import os
import time
import google.generativeai as genai
from dotenv import load_dotenv

load_dotenv()

def generate_answer(question: str, contexts: list[dict]) -> str:
    genai.configure(api_key=os.getenv("GEMINI_API_KEY"))
    model = genai.GenerativeModel("gemini-2.5-flash-lite")

    context_block = ""
    for c in contexts:
        context_block += (
            f"[出典: {c['source_file']} {c['article_no']}({c['article_title']})]\n"
            f"{c['content']}\n\n"
        )

    prompt = f"""あなたは株式会社フィクトワークスの就業規則について回答する社内アシスタントです。
以下の「参考情報」のみを根拠として、質問に対して日本語で簡潔かつ正確に回答してください。
参考情報に記載がない内容については、推測で答えず「就業規則内に該当する情報が見つかりませんでした」と回答してください。

【参考情報】
{context_block}
【質問】
{question}

【回答】"""

    for attempt in range(1, 3):
        try:
            response = model.generate_content(prompt)
            return response.text
        except Exception as e:
            if attempt == 2:
                raise RuntimeError(f"Gemini API呼び出し失敗: {e}")
            time.sleep(3)
```

## 8. RAGコアロジック(`app/rag_service.py`) ※変更なし

```python
from ingest.embedder import get_embedding
from app.db import search_similar_chunks
from app.llm_client import generate_answer

def answer_question(question: str) -> dict:
    if not question or not question.strip():
        raise ValueError("質問を入力してください。")

    # 1. 質問をベクトル化
    query_embedding = get_embedding(question)

    # 2. 類似チャンクを検索
    contexts = search_similar_chunks(query_embedding, top_k=3)

    # 3. 類似度が低いチャンクを除外
    contexts = [c for c in contexts if c["similarity"] >= 0.5]

    # 4. 検索結果なしの場合はフォールバック
    if not contexts:
        return {
            "answer": "就業規則内に関連する情報が見つかりませんでした。",
            "sources": []
        }

    # 5. Geminiで回答生成
    answer = generate_answer(question, contexts)

    sources = [
        {
            "source_file": c["source_file"],
            "article_no": c["article_no"],
            "article_title": c["article_title"],
        }
        for c in contexts
    ]
    return {"answer": answer, "sources": sources}
```

## 9. Streamlitアプリ(`app/main.py`) ★全面変更

### 9.1 変更概要

FastAPIによるREST APIサーバーからStreamlitアプリに全面変更する。`/api/chat`エンドポイントは廃止し、Streamlitの`st.chat_input`が質問受付の窓口となる。

### 9.2 実装コード

```python
import streamlit as st
from app.rag_service import answer_question

st.set_page_config(
    page_title="就業規則チャットボット",
    page_icon="💼",
    layout="centered"
)

st.title("💼 就業規則チャットボット")
st.caption("株式会社フィクトワークス | 就業規則について何でも聞いてください")

# 会話履歴の初期化
if "messages" not in st.session_state:
    st.session_state.messages = []

# 過去の会話を表示
for msg in st.session_state.messages:
    with st.chat_message(msg["role"]):
        st.write(msg["content"])
        if msg.get("sources"):
            with st.expander("📄 出典"):
                for s in msg["sources"]:
                    st.write(f"- {s['source_file']} {s['article_no']}({s['article_title']})")

# 質問入力と回答生成
if question := st.chat_input("就業規則について質問してください..."):
    # ユーザーメッセージ表示
    st.session_state.messages.append({"role": "user", "content": question})
    with st.chat_message("user"):
        st.write(question)

    # 回答生成
    with st.chat_message("assistant"):
        with st.spinner("回答を生成中..."):
            try:
                result = answer_question(question)
                answer = result["answer"]
                sources = result["sources"]
            except Exception as e:
                answer = "回答の生成中にエラーが発生しました。しばらくしてから再度お試しください。"
                sources = []

        st.write(answer)
        if sources:
            with st.expander("📄 出典"):
                for s in sources:
                    st.write(f"- {s['source_file']} {s['article_no']}({s['article_title']})")

    st.session_state.messages.append({
        "role": "assistant",
        "content": answer,
        "sources": sources
    })
```
