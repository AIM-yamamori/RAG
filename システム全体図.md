## 1. データ登録
- Cloud SQLに処理された以下を登録する
  - 元のMarkdownファイル名
  - 章タイトル
  - 条文番号
  - 条文タイトル
  - 条文本文
  - 条文の768次元ベクトル

| ファイル名 | 役割 |
| --- | --- |
| chunker.py | Markdownを条文単位へ分割 |
| embedder.py | 文章・質問を768次元ベクトルへ変換 |
| ingest.py | GCSから取得し、分割・Embedding・DB登録を実行するバッチ |

```
Markdownファイル

↓

chunker.py

↓

条文単位へ分割

↓

embedder.py

↓

Embedding作成

↓

Cloud SQL(pgvector)

↓

保存完了
```

## 2. 質問応答
- 受け取った質問をベクトル化
- Cloud SQLから類似検索をし上位3つを取得
- 検索結果をもとにGemini APIで最適な自然言語で回答を生成

| ファイル名 | 役割 |
| --- | --- |
| main.py | Streamlit画面、チャットUI |
| rag_service.py | RAG全体の制御（検索→回答） |
| db.py | Cloud SQL・pgvectorで類似検索 |
| llm_client.py | Geminiへプロンプト送信し回答生成 |

```
ユーザー

↓

main.py

↓

rag_service.py

↓

Embedding作成

↓

Cloud SQL検索

↓

Gemini

↓

回答
```
