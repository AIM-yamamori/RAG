# テストケース

## 1. テスト概要

### 対象システム
就業規則RAGチャットボット

### 対象画面
Streamlit画面

### テスト目的

- チャット画面が正常に動作すること
- RAG検索が正常に実行されること
- 回答が表示されること
- 出典が表示されること
- エラー時の表示が適切であること

---

# テスト一覧

|No|テスト内容|期待結果|
|---|---|---|
|1|画面表示|正常表示される|
|2|タイトル表示|タイトル・説明が表示される|
|3|通常質問|回答が表示される|
|4|出典表示|出典が表示される|
|5|複数回質問|履歴が保持される|
|6|長文質問|入力チェックされる|
|7|空入力|送信されない|
|8|特殊文字入力|エラーにならない|
|9|検索対象外質問|適切な回答になる|
|10|システムエラー|エラーメッセージ表示|
