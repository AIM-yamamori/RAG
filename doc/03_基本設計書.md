### 3.2 テーブル定義: `rule_chunks`

| カラム名 | 型 | NULL許可 | 説明 |
|---|---|---|---|
| id | SERIAL PRIMARY KEY | NOT NULL | チャンクの一意ID |
| source_file | VARCHAR(255) | NOT NULL | 元のMarkdownファイル名(例:`04_休暇制度.md`) |
| chapter_title | VARCHAR(255) | NULL可 | 章タイトル(例:`第4章 休暇制度`) |
| article_no | VARCHAR(50) | NULL可 | 条文番号(例:`第28条`) |
| article_title | VARCHAR(255) | NULL可 | 条文タイトル(例:`年次有給休暇`) |
| content | TEXT | NOT NULL | チャンクの本文テキスト |
| embedding | VECTOR(768) | NOT NULL | ベクトル埋め込み(768次元 / gemini-embedding-001) |
| created_at | TIMESTAMP | NOT NULL | 登録日時(DEFAULT now()) |

### 3.3 インデックス

| インデックス名 | 対象カラム | 種類 | 目的 |
|---|---|---|---|
| idx_rule_chunks_embedding | embedding | IVFFlat | 類似度検索の高速化(768次元はivfflatの2000次元制限内) |

```sql
CREATE INDEX idx_rule_chunks_embedding
    ON rule_chunks USING ivfflat (embedding vector_cosine_ops)
    WITH (lists = 10);
```

## 4. 画面設計(Streamlit チャットUI)

### 4.1 画面構成

```
┌──────────────────────────────────────────────┐
│  💼 就業規則チャットボット                        │
│  株式会社フィクトワークス | 就業規則について...      │
├──────────────────────────────────────────────┤
│                                                │
│  [st.chat_message("user")]                     │
│   年次有給休暇は何日もらえますか？               │
│                                                │
│  [st.chat_message("assistant")]               │
│   勤続6か月で10日、6年6か月以上で最大20日...    │
│   ▼ 📄 出典 [st.expander]                      │
│     - 04_休暇制度.md 第28条(年次有給休暇)       │
│     - 04_休暇制度.md 第35条(休暇の無給・有給区分) │
│                                                │
├──────────────────────────────────────────────┤
│  [st.chat_input: 就業規則について質問してください...] │
└──────────────────────────────────────────────┘
```

### 4.2 使用するStreamlitコンポーネント

| コンポーネント | 用途 |
|---|---|
| `st.set_page_config` | タイトル・アイコン・レイアウト設定 |
| `st.title` / `st.caption` | アプリ名・サブタイトルの表示 |
| `st.chat_message("user")` | ユーザーメッセージの表示 |
| `st.chat_message("assistant")` | ボットメッセージの表示 |
| `st.chat_input` | 質問入力欄(Enter送信対応) |
| `st.spinner` | 回答生成中のローディング表示 |
| `st.expander("📄 出典")` | 出典情報の折りたたみ表示 |
| `st.session_state.messages` | 会話履歴の管理(リロードで消去) |

## 6. 外部サービス連携仕様

### 6.1 Gemini Embedding API

| 項目 | 値 |
|---|---|
| 用途 | チャンク本文・質問文のベクトル化 |
| 使用モデル | `models/gemini-embedding-001` |
| 出力次元数 | 768次元(`output_dimensionality=768`を必ず明示指定) |
| task_type | `retrieval_document`(取り込み時・検索時ともに同じ値を使用) |
| 認証方式 | APIキー(`GEMINI_API_KEY`環境変数) |
| 無料枠レート制限 | 100リクエスト/分、1,000リクエスト/日 |
| 注意点 | `output_dimensionality`未指定時は3072次元が返りDBとミスマッチになる |

**モデル選定の経緯**

| 試したモデル | 結果 |
|---|---|
| Vertex AI / text-embedding-004 | NG: Python 3.12環境で全入力に同一ベクトルを返す不具合 |
| models/text-embedding-004 (Gemini API) | NG: 404エラー(v1beta未対応) |
| models/embedding-001 (Gemini API) | NG: 404エラー(v1beta未対応) |
| `models/gemini-embedding-001` | **OK: 正常動作確認済み** |

### 6.2 Gemini テキスト生成 API

| 項目 | 値 |
|---|---|
| 用途 | 検索されたコンテキストをもとにした回答生成 |
| 使用モデル | `gemini-2.5-flash-lite` |
| 認証方式 | APIキー(`GEMINI_API_KEY`環境変数) |
| 無料枠レート制限 | 10リクエスト/分、20リクエスト/日 |
| プロンプト構成 | システム指示 + 検索チャンク本文(コンテキスト) + ユーザーの質問 |

**モデル選定の経緯**

| 試したモデル | 結果 |
|---|---|
| gemini-1.5-flash | NG: 404エラー(v1beta未対応) |
| gemini-2.0-flash | NG: 429エラー(無料枠クォータ超過 limit:0) |
| gemini-1.5-flash-latest | NG: 404エラー |
| `gemini-2.5-flash-lite` | **OK: 正常動作確認済み** |

有効なモデルの確認方法: `genai.list_models()` で `generateContent` をサポートするモデルを一覧表示する
