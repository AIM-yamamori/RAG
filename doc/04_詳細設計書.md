## 2. チャンク分割処理(`ingest/chunker.py`)

### 2.1 処理概要

就業規則のMarkdownファイルを読み込み、`## 第n条(タイトル)` の見出し単位を1チャンクとして分割する。

### 2.2 実装コード

```python
import re

def parse_markdown_content(filename: str, text: str) -> list[dict]:
    """Markdownテキストを条文（## 第n条）単位でチャンク分割する"""

    # 章タイトルの抽出(# 第n章 ...)
    chapter_match = re.search(r"^#\s+(.+)$", text, re.MULTILINE)
    chapter_title = chapter_match.group(1).strip() if chapter_match else "不明な章"

    # 条文見出しの検出(## 第n条(タイトル) または ## 第n条)
    pattern = r"^##\s+(第\d+条)(.*)$"
    matches = list(re.finditer(pattern, text, re.MULTILINE))

    chunks = []
    for i, match in enumerate(matches):
        article_no = match.group(1)
        article_title = match.group(2).strip().strip("()")
        start = match.start()
        end = matches[i + 1].start() if i + 1 < len(matches) else len(text)
        content = text[start:end].strip()

        chunks.append({
            "source_file": filename,
            "chapter_title": chapter_title,
            "article_no": article_no,
            "article_title": article_title if article_title else None,
            "content": content
        })

    return chunks
```

### 2.3 戻り値の構造例

```python
[
    {
        "source_file": "04_休暇制度.md",
        "chapter_title": "第4章 休暇制度",
        "article_no": "第28条",
        "article_title": "年次有給休暇",
        "content": "## 第28条(年次有給休暇)\n\n1. 会社は、雇入れの日から..."
    },
    ...
]
```

### 2.4 設計上の注意点

- `00_概要_目次.md` は条文形式ではないためingest.py側でスキップする
- 表(Markdownテーブル)を含む条文も`##`見出し単位で分割するため、表全体が1チャンクに収まる
- 各ファイルのチャンク数(実績): 01_総則.md:7件、02_採用・人事.md:10件 ... 合計82件

## 3. ベクトル化処理(`ingest/embedder.py`) ★全面変更

### 3.1 変更概要

Vertex AI SDK(`vertexai.language_models.TextEmbeddingModel`)からGemini API(`google.generativeai.embed_content`)に変更した。

**変更理由:** Vertex AI SDKがPython 3.12環境で、入力テキストの内容に関わらず全て同一のベクトルを返す不具合が発生した。エラーは一切発生せず「動いているように見えて壊れている」状態であり、`check_vector.py`で2つの異なる質問に対するベクトルを比較することで発見した。

### 3.2 実装コード

```python
import os
import google.generativeai as genai
from dotenv import load_dotenv

load_dotenv()
genai.configure(api_key=os.getenv("GEMINI_API_KEY"))

def get_embedding(text: str) -> list[float]:
    """Gemini API(gemini-embedding-001)を用いて768次元のベクトルを取得する"""
    result = genai.embed_content(
        model="models/gemini-embedding-001",
        content=text,
        task_type="retrieval_document",
        output_dimensionality=768    # 必須: 未指定時は3072次元が返りDBとミスマッチになる
    )
    return result["embedding"]
```

### 3.3 重要な設計上の注意点

| 項目 | 内容 |
|---|---|
| モデル名 | `models/gemini-embedding-001`(models/プレフィックス必須) |
| 次元数 | `output_dimensionality=768`を**必ず明示指定する** |
| task_type | 取り込み時・検索時ともに`retrieval_document`を使用 |
| Vertex AI | 使用しない(Python 3.12環境での不具合のため) |

### 3.4 モデル選定の経緯

| 試したモデル | 結果 | 原因 |
|---|---|---|
| Vertex AI / text-embedding-004 | NG | Python 3.12環境で全入力に同一ベクトルを返す不具合 |
| models/text-embedding-004 | NG: 404エラー | Gemini API v1beta未対応 |
| models/embedding-001 | NG: 404エラー | Gemini API v1beta未対応 |
| **models/gemini-embedding-001** | **OK** | 正常動作確認済み |

有効なモデルの確認方法:

## 4. 取り込みバッチ(`ingest/ingest.py`)

### 4.1 実装コード

```python
import os
import sqlalchemy
from google.cloud.sql.connector import Connector
from google.cloud import storage
from ingest.chunker import parse_markdown_content
from ingest.embedder import get_embedding

BUCKET_NAME = "fictworks-rule-data-501004"
INSTANCE_CONNECTION_NAME = "my-project-rag-501004:asia-northeast1:rag-rules-db"
DB_USER = "rag_user"
DB_PASS = "RagUserPass456!"
DB_NAME = "rag_db"

def get_engine():
    connector = Connector()
    def getconn():
        return connector.connect(
            INSTANCE_CONNECTION_NAME, "pg8000",
            user=DB_USER, password=DB_PASS, db=DB_NAME,
        )
    return sqlalchemy.create_engine("postgresql+pg8000://", creator=getconn)

def main():
    print("[INFO] データ取り込みバッチを開始します。")

    # GCSからファイル取得
    client = storage.Client()
    bucket = client.bucket(BUCKET_NAME)
    blobs = list(bucket.list_blobs(prefix="company_rule/"))

    all_chunks = []
    for blob in blobs:
        if not blob.name.endswith(".md"):
            continue
        if "00_概要_目次" in blob.name:    # 目次ファイルはスキップ
            continue
        filename = os.path.basename(blob.name)
        text = blob.download_as_text(encoding="utf-8")
        chunks = parse_markdown_content(filename, text)
        all_chunks.extend(chunks)
        print(f"[INFO] パース完了: {filename} ({len(chunks)} チャンク)")

    print(f"[INFO] 総チャンク数: {len(all_chunks)} 件 ベクトル化+DB格納を開始します。")

    engine = get_engine()
    with engine.connect() as conn:
        conn.execute(sqlalchemy.text("TRUNCATE TABLE rule_chunks;"))  # 冪等性確保

        success_count = 0
        for chunk in all_chunks:
            try:
                embedding = get_embedding(chunk["content"])
                conn.execute(
                    sqlalchemy.text("""
                        INSERT INTO rule_chunks
                            (source_file, chapter_title, article_no, article_title, content, embedding)
                        VALUES
                            (:source_file, :chapter_title, :article_no, :article_title, :content, :embedding)
                    """),
                    {**chunk, "embedding": str(embedding)}
                )
                success_count += 1
                print(f"  [{success_count}] {chunk['source_file']} {chunk['article_no']} 登録完了")
            except Exception as e:
                print(f"[WARNING] スキップ: {chunk.get('article_no')} / エラー: {e}")

        conn.commit()

    print(f"\n[SUCCESS] 完了！ 登録件数: {success_count} / {len(all_chunks)}")

if __name__ == "__main__":
    main()
```

## 5. DB接続処理(`app/db.py`)

### 5.1 実装コード

```python
import os
import sqlalchemy
from google.cloud.sql.connector import Connector

INSTANCE_CONNECTION_NAME = "my-project-rag-501004:asia-northeast1:rag-rules-db"
DB_USER = "rag_user"
DB_PASS = "RagUserPass456!"
DB_NAME = "rag_db"

_engine = None

def get_engine():
    global _engine
    if _engine is None:    # 初回のみ接続を作成(使い回す)
        connector = Connector()
        def getconn():
            return connector.connect(
                INSTANCE_CONNECTION_NAME, "pg8000",
                user=DB_USER, password=DB_PASS, db=DB_NAME,
            )
        _engine = sqlalchemy.create_engine(
            "postgresql+pg8000://",
            creator=getconn,
        )
    return _engine

def search_similar_chunks(query_embedding: list[float], top_k: int = 3) -> list[dict]:
    """pgvectorでコサイン類似度の高いチャンクを検索する"""
    engine = get_engine()
    vector_str = "[" + ",".join(str(v) for v in query_embedding) + "]"

    sql = sqlalchemy.text("""
        SELECT
            source_file, chapter_title, article_no, article_title, content,
            1 - (embedding <=> CAST(:vec AS vector)) AS similarity
        FROM rule_chunks
        ORDER BY embedding <=> CAST(:vec AS vector)
        LIMIT :top_k
    """)

    results = []
    with engine.connect() as conn:
        rows = conn.execute(sql, {"vec": vector_str, "top_k": top_k})
        for r in rows:
            results.append({
                "source_file":   r[0],    # pg8000はインデックスアクセスを使用
                "chapter_title": r[1],    # r.source_file のような属性アクセスは不可
                "article_no":    r[2],
                "article_title": r[3],
                "content":       r[4],
                "similarity":    float(r[5]),
            })
    return results
```

### 5.2 重要な設計上の注意点

**pg8000はカラム名での属性アクセスが不可**

psycopg2では`r.source_file`のようなアクセスができるが、pg8000では`r[0]`のようなインデックスアクセスが必要。この仕様の違いを見落とすと`NoneType is not subscriptable`エラーが発生する。

**コサイン類似度の計算**

pgvectorの`<=>`演算子はコサイン**距離**を返す(0に近いほど似ている)。類似度(1に近いほど似ている)に変換するため `1 - (embedding <=> ...)` を使用する。

## 6. LLM呼び出し処理(`app/llm_client.py`)

### 6.1 実装コード

```python
import os
import time
import google.generativeai as genai
from dotenv import load_dotenv

load_dotenv()

def generate_answer(question: str, contexts: list[dict]) -> str:
    """検索結果をコンテキストとしてGeminiに回答を生成させる"""
    genai.configure(api_key=os.getenv("GEMINI_API_KEY"))
    model = genai.GenerativeModel("gemini-2.5-flash-lite")

    # コンテキストブロックの構築
    context_block = ""
    for c in contexts:
        context_block += (
            f"[出典: {c['source_file']} {c['article_no']}({c['article_title']})]\n"
            f"{c['content']}\n\n"
        )

    prompt = f"""あなたは株式会社フィクトワークスの就業規則について回答する社内アシスタントです。
以下の「参考情報」のみを根拠として、質問に対して日本語で簡潔かつ正確に回答してください。
参考情報に記載がない内容については、推測で答えず「就業規則内に該当する情報が見つかりませんでした」と回答してください。

【参考情報】
{context_block}
【質問】
{question}

【回答】"""

    for attempt in range(1, 3):
        try:
            response = model.generate_content(prompt)
            return response.text
        except Exception as e:
            if attempt == 2:
                raise RuntimeError(f"Gemini API呼び出し失敗: {e}")
            time.sleep(3)
```

| gemini-2.0-flash | NG: 429エラー | 無料枠クォータ超過(limit: 0) |
| gemini-1.5-flash-latest | NG: 404エラー | v1beta未対応 |

### 6.3 プロンプト設計の意図

`「参考情報のみを根拠とすること」`を明示する理由: LLMは指示がないと学習済みの一般知識で「それらしく」答えてしまう。RAGの意味は「検索した情報だけを根拠にする」ことなので、この一文でハルシネーションを抑制する。

## 7. RAGコアロジック(`app/rag_service.py`)

### 7.1 実装コード

```python
import os
import sys
sys.path.append(os.path.join(os.path.dirname(__file__), ".."))

from ingest.embedder import get_embedding
from app.db import search_similar_chunks
from app.llm_client import generate_answer

def answer_question(question: str) -> dict:
    """質問に対してRAGパイプラインで回答を生成する"""

    # 入力バリデーション
    if not question or not question.strip():
        raise ValueError("質問を入力してください。")
    if len(question) > 500:
        raise ValueError("質問は500文字以内で入力してください。")

    # Step1: 質問をベクトル化
    query_embedding = get_embedding(question)

    # Step2: 類似チャンクを検索(上位3件)
    contexts = search_similar_chunks(query_embedding, top_k=3)

    # Step3: 類似度が低いチャンクを除外(0.5未満は無関係と判断)
    contexts = [c for c in contexts if c["similarity"] >= 0.5]

    # Step4: 該当なしの場合はフォールバック
    if not contexts:
        return {
            "answer": "就業規則内に関連する情報が見つかりませんでした。",
            "sources": []
        }

    # Step5: Geminiで回答生成
    answer = generate_answer(question, contexts)

    sources = [
        {
            "source_file":  c["source_file"],
            "article_no":   c["article_no"],
            "article_title": c["article_title"],
        }
        for c in contexts
    ]
    return {"answer": answer, "sources": sources}
```

### 7.2 類似度閾値(0.5)の意味

- 1.0 に近い: 質問と条文の意味が非常に近い
- 0.5 以上: ある程度関連がある(採用)
- 0.5 未満: 無関係な質問の可能性が高い(フォールバックに回す)

今回の実績では、正しい条文が上位にヒットする場合の類似度は0.84〜0.87程度。

## 8. Streamlitアプリ(`app/main.py`) ★全面変更

### 8.1 実装コード

```python
import streamlit as st
import os
import sys
sys.path.append(os.path.join(os.path.dirname(__file__), ".."))

from app.rag_service import answer_question

st.set_page_config(
    page_title="就業規則RAGチャットボット",
    page_icon="💼",
    layout="centered"
)

st.title("💼 就業規則チャットボット")
st.caption("株式会社フィクトワークス | 就業規則について質問を入力してください")

# 会話履歴の初期化
if "messages" not in st.session_state:
    st.session_state.messages = []

# 過去の会話を再描画
for msg in st.session_state.messages:
    with st.chat_message(msg["role"]):
        st.write(msg["content"])
        if msg["role"] == "assistant" and msg.get("sources"):
            with st.expander("📄 出典"):
                for s in msg["sources"]:
                    st.write(f"- {s['source_file']} {s['article_no']}({s['article_title']})")

# 質問入力と回答生成
if question := st.chat_input("就業規則について質問してください..."):

    # ユーザーメッセージ表示 & 履歴追加
    st.session_state.messages.append({"role": "user", "content": question})
    with st.chat_message("user"):
        st.write(question)

    # 回答生成
    with st.chat_message("assistant"):
        with st.spinner("回答を生成中..."):
            try:
                result = answer_question(question)
                answer = result["answer"]
                sources = result["sources"]
            except ValueError as e:
                answer = f"入力エラー: {str(e)}"
                sources = []
            except Exception as e:
                answer = "回答の生成中にエラーが発生しました。しばらくしてから再度お試しください。"
                sources = []

        st.write(answer)
        if sources:
            with st.expander("📄 出典"):
                for s in sources:
                    st.write(f"- {s['source_file']} {s['article_no']}({s['article_title']})")

    # 履歴に追加
    st.session_state.messages.append({
        "role": "assistant",
        "content": answer,
        "sources": sources
    })
```
